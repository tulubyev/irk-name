# Фото на VPS: план реализации

**Goal:** разрешить загрузку фото в редакторе при хранении карточек в GitHub.
**Architecture:** независимый выбор fs/S3; общий каталог media для админки и nginx.
**Tech Stack:** TypeScript, sharp, Node.js, Docker Compose.
**Spec:** ../specs/2026-11-14-admin-local-photos-design.md (согласовано пользователем).

## Ограничения и проверки

Сохранять текущую авторизацию и CSRF; три размера WebP и имя с хэшем. Проверить неверные ключи, отсутствие S3, явный fs с S3-ключами, повреждённые изображения и атомарную запись. Не удалять старые файлы.
